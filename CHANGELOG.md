## [v0.10.0] - 2026-08-23 ([`4c90829`](https://github.com/grokify/awsgo/commit/4c90829))

### Highlights

- New `awsgo` Cobra CLI (`cmd/awsgo`) as a unified toolbox for AWS operations, starting with `awsgo rds param-read`
- New `regions.RegionsAzure()` Azure region dataset mirroring the existing AWS `Regions()`, plus a `parseandcount` CLI for region footprint analysis
- `rdsutil`: `DiffParameterValues()` for comparing RDS parameter maps
- `inspector2util`: streaming reader for large findings JSON files

### Added

- `cmd/awsgo`: scaffold Cobra CLI with `rds param-read` subcommand ([`6970a70`](https://github.com/grokify/awsgo/commit/6970a70))
