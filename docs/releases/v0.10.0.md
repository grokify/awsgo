# Release Notes - v0.10.0

## Overview

This release introduces **`awsgo`**, a unified Cobra CLI intended to replace the repo's pattern of one throwaway `main` package per `*util/cmd/` subdirectory, adds **Azure region data** alongside the existing AWS region dataset, and rounds out `rdsutil`/`inspector2util` with parameter-diffing and streaming-read utilities.

## Highlights

- New `awsgo` Cobra CLI (`cmd/awsgo`), starting with `awsgo rds param-read`
- New `regions.RegionsAzure()` dataset mirroring the existing AWS `Regions()`, plus a `parseandcount` CLI for region footprint analysis
- `rdsutil.DiffParameterValues()` for comparing RDS parameter maps
- `inspector2util.ReadFileListFindingsOutputStream()` for streaming large findings JSON files

## Added

### `awsgo` CLI

A single `awsgo` binary intended to grow into a toolbox CLI over time (`awsgo rds ...`, `awsgo regions ...`, etc.). The first migrated subcommand reads an RDS `DescribeEngineDefaultParameters`/`DescribeDBParameters` JSON export and prints the parsed parameters plus a count:

```bash
awsgo rds param-read --file db-perf-group_mysql8.json
```

### Azure Region Data

`regions.RegionsAzure()` covers the standard Azure regions, following the existing `regions.Regions()` (AWS) pattern:

```go
import "github.com/grokify/awsgo/regions"

azureRegions := regions.RegionsAzure()
```

A companion `parseandcount` CLI reads a file of region codes (AWS or Azure) and reports counts by country/region grouping (US, CA, DACH, Nordic, Benelux, GB, Eastern Europe, Near/Middle East, ANZ, CN, JP, rest of APAC, rest of Europe):

```bash
go run ./regions/cmd/parseandcount --file regions.txt
```

### `rdsutil` Parameter Diffing

`DiffParameterValues()` compares two parameter maps and reports additions, removals, and changed values:

```go
import "github.com/grokify/awsgo/rdsutil"

diffs := rdsutil.DiffParameterValues(params1, params2)
```

### `inspector2util` Streaming Reader

`ReadFileListFindingsOutputStream()` reads a findings JSON export and invokes a callback per finding, avoiding loading the entire file into memory:

```go
import "github.com/grokify/awsgo/inspector2util"

err := inspector2util.ReadFileListFindingsOutputStream(filename, func(f types.Finding) error {
    // process finding
    return nil
})
```

## Changed

- `rdsutil`: retired the `cmd/param_read` example CLI, superseded by `awsgo rds param-read`. Its fixture JSON files moved to `rdsutil/testdata/` (idiomatic Go fixture location) rather than being deleted, since they're real RDS parameter-group exports useful as test data.

## Documentation

- `README.md` rewritten with an accurate package table and a CLI section for `cmd/awsgo`
- `docs/` seeded as the home for a future MkDocs site, starting with curated AWS architecture diagramming references (Workload Discovery, CloudMapper, cfn-diagram, etc.)
- `inspector2util` package README added

Routine dependency maintenance: AWS SDK for Go v2 service clients (`credentials`, `config`, `costexplorer`, `trustedadvisor`, `secretsmanager`, `dynamodb`, `feature/dynamodb/attributevalue`, `inspector2`), `github.com/grokify/mogo`, and GitHub Actions (`actions/checkout`, `actions/setup-go`).
