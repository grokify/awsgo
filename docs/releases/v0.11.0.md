# Release Notes - v0.11.0

## Overview

This release integrates **`inspector2util`** with the shared **findingspec** finding
model and **removes the govex dependency** from the module: AWS Inspector findings
now convert to `findingspec.Finding`, and POA&M generation moves to govex's generic
findingspec consumer. It also adds a new **`sfnutil`** Step Functions helper package.

## Highlights

- `inspector2util` converts AWS Inspector findings to the shared
  [findingspec](https://github.com/plexusone/findingspec) IR and **no longer
  depends on govex**.
- POA&M is now generated generically from findingspec via govex
  `reports/poam.FromFindings` — available to every scanner adapter, not just
  Inspector.
- New `sfnutil` package: AWS Step Functions (SDK v2) helpers.

## Added

### `inspector2util` → findingspec

AWS Inspector2 package-vulnerability findings now convert to the canonical
`findingspec.Finding` (security domain), one finding per vulnerable package, with
ECR container images mapped to `type=container` and EC2 instances to
`type=runtime`:

```go
set := inspector2util.Findings(findings).Findings(inspector2util.FindingSpecOptions{})
// *findingspec.FindingSet — feed to dashboards, prioritization, or govex POA&M
```

### `sfnutil`

A new helper package for AWS Step Functions (SDK v2).

## Changed

- `inspector2util` severity canonicalization (`FindingSeverity`, `VendorSeverity`)
  now uses the findingspec severity vocabulary (backed by priority-frameworks)
  instead of `govex/severity`.

## Removed

- **`inspector2util` no longer depends on `govex`.** The govex-coupled POA&M,
  field-value, and table-rendering layer was removed
  (`VulnerabilityField`, `POAMItemValue`, `POAMTable`, `TablePackages`,
  `ReportOptions`, `ImageVulnerabilitesReporter`). This is a breaking change for
  callers of those APIs.

  **Migration:** produce findings with `inspector2util.Findings(...).Findings(...)`
  and generate POA&M from them with govex `reports/poam.FromFindings([]findingspec.Finding, ...)`.

## Dependencies

- Added `github.com/plexusone/findingspec` v0.1.0.
- Removed `github.com/grokify/govex`.
